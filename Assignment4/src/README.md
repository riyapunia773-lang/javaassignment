
# Simple Calculator

## Program Description

This is a simple Java calculator program.
It adds positive integers and stores the total.
It can also reset the total to zero.

## Calculator Class

The Calculator class has three methods:

1. reset() - Sets the total to zero.
2. add(int number) - Adds a number to the total.
3. getValue() - Returns the current total.

If a negative number is entered, the program
throws an exception.

## Main Class

The Main class tests the Calculator class.
It adds 5, 10 and 3. The result is 18.
After that, it resets the calculator to zero.

## Benefits of GitHub Copilot

- Saves time when writing code.
- Suggests different ways to solve problems.
- Helps beginners understand programming.
- Can explain code.

## Disadvantages of GitHub Copilot

- Sometimes it suggests incorrect code.
- Beginners may not understand all suggestions.
- It is important to check the generated code.
